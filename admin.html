The database isn’t connected yet, so changes you make here are only saved in this browser. The shop pages in this browser show them straight away, so you can try things out.

To make them real for everyone: press Download catalog.js, put the file in the website folder in place of the old one (and any new photos it downloads into the images folder), then publish the site.

Connect the database (so the admin works live, from anywhere)
  1. Create a free project at supabase.com.
  2. In SQL Editor, paste everything from supabase/schema.sql and press Run. Then do the same with supabase/privacy.sql.
  3. Still in the SQL Editor, add yourself as the owner:
    insert into public.admins (email, role) values ('you@example.com', 'owner');
  4. Copy the Project URL and anon public key (Project Settings → API) into config.js.
  5. Come back here and sign in with that email.

The README explains every step.
